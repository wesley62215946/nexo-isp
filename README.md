# Nexo ISP — EliteSoft Integrator Front-end

Demonstração independente de interface inspirada no Integrator 6, construída apenas com HTML, CSS e JavaScript.

## Executar localmente

Abra `index.html` em um navegador moderno. Não há dependências, build, servidor ou backend obrigatórios.

## Funcionalidades

- Início com indicadores operacionais.
- Navegação lateral expansível e abas.
- Pesquisa e cadastro de clientes com ficha detalhada.
- Oito clientes fictícios com planos e configurações distintas.
- Prospectos, atendimentos, ordens de serviço e agenda técnica.
- Pontos de acesso, Site Survey, mensagens, BI e gráfico de NAS.
- Financeiro, orçamento e painel de autenticações.
- Filtros, edição, operações locais, exportação CSV e persistência via `localStorage`.
- Animações e preferência para reduzir/desativar movimento.

## Arquivos

- `index.html` — estrutura da aplicação.
- `styles.css` — interface responsiva inspirada nas referências visuais.
- `app.js` — navegação, dados de demonstração e operações locais.

## Limitações

Este projeto é somente front-end. Não há API, backend, autenticação real, integração RADIUS/roteadores, pagamentos ou notificações externas. Os dados são fictícios e permanecem no armazenamento local do navegador.

O aviso de certificado SSL foi removido da interface.
